# Eclipse Simple ADB: test builds

Simple ADB is a phone app that controls a Wear OS watch (made and tested on the Galaxy Watch8) over ADB, with an optional Bluetooth helper app on the watch.

## Download the latest test build

**[SimpleADB-v2.17-test.apk](https://github.com/Squad1996/eclipse-simpleADB/raw/main/SimpleADB-v2.17-test.apk)** (about 13 MB, version 2.17)

SHA-256: `409121df74350acc0dad350bc9b201f44dd09dfcec384e2cf6dfcf0bd77646e6`

## Install

1. Download the APK on your Android phone and open it. Allow "install unknown apps" for your browser or file manager when asked.
2. Open Simple ADB and pair your watch (turn on Wireless debugging on the watch first).
3. Optional: in the Bluetooth helper card on the Watch tab, tap **Set up** (or **Set up again** after an update). It installs the helper on the watch. This needs Wi-Fi once; afterwards Bluetooth is enough for most things.

## Updating

Install the new APK over the old one, then tap **Update the helper** (or **Set up again**) in the Bluetooth helper card.

## Reporting a problem

Open the Bluetooth helper card, tap **Details**, then **Copy report for testers**, and paste it in your message together with what you did and what went wrong.

This is a test build and can have bugs.
